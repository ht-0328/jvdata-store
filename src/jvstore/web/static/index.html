JRA-VAN データ取得・管理

使い方：起動・停止・画面の開き直し

サーバーの起動・停止・画面の開き直しは、操作パネルで行います。操作パネルは、jvdata-store フォルダの run.bat をダブルクリックすると開く小さなウィンドウです。ブラウザからはサーバーを起動できないため、ブラウザの画面とは分けています。

やりたいこと操作
起動する run.bat をダブルクリックします。止まっていれば自動で起動し、この画面が開きます。停止したあとは、操作パネルの「起動」で起動し直せます。
閉じた画面を開き直す 操作パネルの「画面を開く」を押します。操作パネルも閉じていたら、run.bat をもう一度ダブルクリックします。動いているサーバーをそのまま使うので、取得の途中でも止まりません。
停止する 操作パネルの「停止」を押します。取得の途中なら「終わってから停止しますか？」と聞かれます。「はい」なら取得が終わったときに自動で停止し、「いいえ」なら停止しません。
停止の予約をやめる 操作パネルの「予約を取り消す」を押します。

ブラウザのタブや操作パネルを閉じても、サーバーは止まりません。取得の途中で止めることはできません。途中で止めると、データが途中までしか入らないためです。

JRA-VAN データ取得

過去のレース・競走馬・血統・調教などを取得します。初回は指定年数ぶん、2回目からは前回以降の更新を取り込みます。


例：1年取得済みで10年に広げる場合はチェックしてください。年数の変更だけでは古い年は追加されません。

初回や再取得は数十分〜数時間、保存容量は数GBになることがあります。取得中はデータの閲覧・予想を待機します。
利用キーが未登録なら「JV-Link設定」で登録してください。設定画面はこのPCに開きます。

速報の取得（発走前のオッズ・馬体重・天候と馬場状態・マイニング予想）

上の「取得する」で入るのは、確定したあとのデータだけです。発走前に要るオッズ・人気・馬体重・天候と馬場状態・マイニング予想・取消や騎手変更は、開催日を指定してここで取得します。何度取り直しても構いません（新しい内容に置き換わり、オッズは発表時刻ごとに残ります）。

オッズは発売が始まってから（前日発売があれば前日の夜から）、馬体重は発走の約1時間前から、マイニング予想は出馬表の発表後から入ります。まだ発表されていないものは「該当データなし」と出ます。速報の提供期間は1週間です。1日ぶんで1分ほどかかります。
