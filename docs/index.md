# JV-Data の読み方

JRA-VAN Data Lab. が配信する **JV-Data** の仕様を、実際に取得したデータで確かめながら
まとめたものです。SDK 同梱の仕様書（PDF・xlsx）が一次資料で、ここはその案内役です。

## どれから読むか

**JV-Data を初めて触るなら、01 から順に読んでください。** 4本で全体が分かります。

| # | ページ | 何が分かるか |
| :--- | :--- | :--- |
| 01 | [JV-Data の全体像](01-overview.md) | 何が配信されていて、どう受け取るか |
| 02 | [レコードの読み方](02-record-format.md) | 1レコードをどう解くか。**ここが核心です** |
| 03 | [データ種別と提供タイミング](03-dataspecs.md) | 何をいつ取れるか。取れないものは何か |
| 04 | [レコードのつながり](04-relations.md) | 38の表をどう結合するか |

調べものなら、参照編に直接飛んでください。

| ページ | 中身 |
| :--- | :--- |
| [レコード索引](reference/index.md) | 全38レコードの一覧。ここから各レコードへ |
| [コード表](reference/codes.md) | 競馬場コード・馬場状態コードなど19種類 |

## このドキュメントの立場

**仕様書の置き換えではありません。** 仕様書は網羅的ですが、
「まず何を知ればいいか」が分かりにくい形をしています。ここでは順序を付け、
実データを添えて、読み解けるようにすることを狙っています。

判断に迷ったときは、必ず一次資料に戻ってください。

| 資料 | 場所 | 何の一次資料か |
| :--- | :--- | :--- |
| JV-Data仕様書 4.9.0.1 | SDK の `ドキュメント/JV-Data仕様書_4.9.0.1.pdf` | レコードの中身・コード表 |
| 同 xlsx 版 | 同 `JV-Data仕様書_4.9.0.1.xlsx` | 上と同じ内容。**機械可読なのでこちらを使います** |

## 参照編は生成物です

`reference/` の下は**手で書いていません**。仕様書の xlsx から生成しています。
仕様が改訂されたら、次の順で作り直します。

```powershell
# 1. レイアウト定義を作り直す
uv run jvstore spec build --xlsx "...\JV-Data仕様書_X.X.X.xlsx" --strict
uv run pytest -q

# 2. 参照編を作り直す
uv run python tools/gen_spec_docs.py --xlsx "...\JV-Data仕様書_X.X.X.xlsx"
```

01〜04 は手で書いています。改訂時は目視で確認してください。
