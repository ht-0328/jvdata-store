# レコードのつながり

**38の表は、いくつかの決まったキーで結ばれています。** そこさえ押さえれば、
知らない表でも結合の仕方が分かります。

## 背骨は2つ

### レースキー（6項目）

```
開催年 + 開催月日 + 競馬場コード + 開催回[第N回] + 開催日目[N日目] + レース番号
```

**レース単位の表は、ほぼ全部このキーを持ちます。** そのまま結合できます。

| レコード | 内容 |
| :--- | :--- |
| `RA` | レース詳細 |
| `HR` | 払戻 |
| `H1` `H6` | 票数 |
| `O1`〜`O6` | オッズ |
| `TK` | 特別登録馬 |
| `DM` `TM` | データマイニング予想 |
| `WH` `WE` `AV` `JC` `TC` `CC` | 速報系（`WE` は開催日まで） |

`YS`（開催スケジュール）だけはレース番号を持ちません。開催日単位だからです。

### 血統登録番号（10桁）

**馬を指す唯一の番号です。** 生年4桁＋品種1桁＋連番5桁でできています。

| レコード | 内容 |
| :--- | :--- |
| `UM` | 競走馬マスタ |
| `SK` | 産駒マスタ |
| `HY` | 馬名の意味由来 |
| `HS` | 競走馬市場取引価格 |
| `SE` | 馬毎レース情報（レースキーと組で持つ） |
| `CK` | 出走別着度数（〃） |
| `HC` `WC` | 調教（調教年月日と組で持つ） |

## 全体像

```
                    ┌──────────────┐
   レースキー ──────>│  RA レース詳細 │
        │            └──────────────┘
        ├──> HR 払戻 / H1 H6 票数 / O1〜O6 オッズ
        ├──> TK 特別登録馬 / DM TM マイニング予想
        │
        └──> SE 馬毎レース情報 ──┬── 血統登録番号 ──> UM 競走馬マスタ
             (レースキー+馬番     │                        │
              +血統登録番号)      │                        ├─ 調教師コード ─> CH
                                  │                        ├─ 馬主コード ───> BN
                                  │                        ├─ 生産者コード ─> BR
                                  │                        └─ 3代血統 ──────> HN 繁殖馬
                                  ├── 騎手コード ────> KS 騎手マスタ
                                  ├── 調教師コード ──> CH 調教師マスタ
                                  └── 馬主コード ────> BN 馬主マスタ
```

`SE` が要です。**レースと馬をつなぐ唯一の表**で、1レース1頭につき1行あります。

## リンクの一覧

仕様書が「〜マスタへリンク」と明記している項目です。

| 元 | 項番 | 項目 | 先 |
| :--- | ---: | :--- | :--- |
| `SE` 馬毎レース情報 | 20 | 調教師コード | `CH` 調教師マスタ |
| | 22 | 馬主コード | `BN` 馬主マスタ |
| | 30 | 騎手コード | `KS` 騎手マスタ |
| `UM` 競走馬マスタ | 20 | 調教師コード | `CH` 調教師マスタ |
| | 23 | 生産者コード | `BR` 生産者マスタ |
| | 26 | 馬主コード | `BN` 馬主マスタ |
| `SK` 産駒マスタ | 11 | 生産者コード | `BR` 生産者マスタ |
| `HS` 市場取引価格 | 4 | 血統登録番号 | `UM` 競走馬マスタ |
| | 5 | 父馬 繁殖登録番号 | `HN` 繁殖馬マスタ |
| | 6 | 母馬 繁殖登録番号 | `HN` 繁殖馬マスタ |
| `HY` 馬名の意味由来 | 4 | 血統登録番号 | `UM` 競走馬マスタ |
| `JC` 騎手変更 | 14, 18 | 騎手コード | `KS` 騎手マスタ |

血統は `UM` の `3代血統情報`（繰返しブロック）と `SK` 産駒マスタが
`繁殖登録番号` で `HN` 繁殖馬マスタを指します。系統をたどるなら `BT` 系統情報です。

## 結合の例

DuckDB でのテーブル名は、レコード種別IDの小文字です。

**以下の SQL は、実際に取得したデータ（2026年8月29日・30日、72レース）で
動作を確認しています。**

### あるレースの出走馬と、その馬のマスタ情報

```sql
SELECT se."馬番", se."馬名", um."生年月日", ch."調教師名"
FROM se
JOIN um ON um."血統登録番号" = se."血統登録番号"
LEFT JOIN ch ON ch."調教師コード" = se."調教師コード"
WHERE se."開催年" = '2026' AND se."開催月日" = '0829'
  AND se."競馬場コード" = '01' AND se."開催回[第N回]" = '02'
  AND se."開催日目[N日目]" = '03' AND se."レース番号" = '01'
ORDER BY se."馬番";
```

### レース詳細と払戻

払戻は賭式ごとの子テーブルに分かれています。単勝なら `hr__単勝払戻` です。

```sql
SELECT ra."競走名本題", t."馬番", t."払戻金"
FROM ra
JOIN "hr__単勝払戻" t USING ("開催年", "開催月日", "競馬場コード",
                             "開催回[第N回]", "開催日目[N日目]", "レース番号")
WHERE ra."開催年" = '2026' AND t."払戻金" <> '';
```

レースキーは6列とも同名なので、`USING` でまとめて書けます。

> [!NOTE]
> **`競走名本題` は特別競走にしか入りません**
>
> 実データで確かめると、札幌・新潟の2日間72レースのうち**19レースにしか
> 名前が入っていませんでした**。一般競走は空欄です。
>
> 表示用の名前が要るなら、`競走種別コード`・`競走条件コード`・`距離` から
> 組み立てることになります（「3歳未勝利」など）。

### ある馬の過去走

```sql
SELECT se."開催年", se."開催月日", se."確定着順", ra."競走名本題", ra."距離"
FROM se
JOIN ra USING ("開催年", "開催月日", "競馬場コード",
               "開催回[第N回]", "開催日目[N日目]", "レース番号")
WHERE se."血統登録番号" = '2021104123'
ORDER BY se."開催年" DESC, se."開催月日" DESC;
```

> [!WARNING]
> **並び順を当てにしない**
>
> 仕様書は「レコードの収録順序には仕様はありません」と明記しています。
> **必ず `ORDER BY` を書いてください。**

## 繰返しブロックの結合

繰返しブロックは子テーブルになります。**親のキー ＋ `_連番`** で結合します。

```sql
-- 3連単オッズの上位10点
SELECT o."組番", o."オッズ", o."人気順"
FROM "o6__3連単オッズ" o
WHERE o."開催年" = '2026' AND o."開催月日" = '0829'
  AND o."競馬場コード" = '01' AND o."レース番号" = '01'
ORDER BY CAST(o."人気順" AS INTEGER)
LIMIT 10;
```

どのブロックがどの子テーブルになるかは、各レコードの参照ページに書いてあります。
例: [reference/O6.md](reference/O6.md)
