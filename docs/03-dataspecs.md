# データ種別と提供タイミング

**データ種別IDは「取得の単位」です。** `JVOpen` / `JVRTOpen` に渡す4文字の名前で、
1つのIDが複数のレコード種別を含みます。

このページは、**何をいつ取れるか**と、**取れないものは何か**をまとめます。
一次資料は JV-Data仕様書の「データ種別一覧」「データ提供タイミング･提供単位」シートです。

## 蓄積系 — 期間を指定して取る

`JVOpen(種別, 期間, option)` で取ります。「セットアップ」列の印は、その取得方法を
指定できることを表します。多くは1年より前にも遡れますが、`TOKU` は今週・来週分のみです。

| ID | 名称 | セットアップ | 含まれるレコード |
| :--- | :--- | :---: | :--- |
| `TOKU` | 特別登録馬情報 | ○（今週・来週分のみ） | TK |
| `RACE` | レース情報 | ○ | RA SE HR H1 H6 O1 O2 O3 O4 O5 O6 WF JG |
| `DIFF` / `DIFN` | 蓄積情報 | ○ | UM KS CH BR BN RC RA SE |
| `BLOD` / `BLDN` | 血統情報 | ○ | HN SK BT |
| `MING` | マイニング情報 | ○ | DM TM |
| `SNAP` / `SNPN` | 出走時点情報 | ○ | CK |
| `SLOP` | 坂路調教情報 | ○ | HC |
| `WOOD` | ウッドチップ調教情報 | ○ | WC |
| `YSCH` | 開催スケジュール | ○ | YS |
| `HOSE` / `HOSN` | 競走馬市場取引価格情報 | ○ | HS |
| `HOYU` | 馬名の意味由来情報 | ○ | HY |
| `COMM` | 各種解説情報 | ○ | CS |
| `TCOV` / `TCVN` | 補てん情報（特別登録馬） | | UM CH BR BN RC RA SE |
| `RCOV` / `RCVN` | 補てん情報（レース情報） | | UM KS CH BR BN RC RA SE |

> [!CAUTION]
> **新旧2つある種別は、必ず新しい方を使う**
>
> `DIFF`/`DIFN`、`BLOD`/`BLDN`、`SNAP`/`SNPN`、`HOSE`/`HOSN` は**同じ情報の
> 新旧2版**です。新版（`N` の付く方）は繁殖登録番号・生産者コード・生産者名の
> サイズ拡張に対応しています。
>
> **仕様書 4.9.0.1 のレイアウトと一致するのは新版だけです。** 旧版を取ると
> `UM` と `BR` のバイト位置がずれ、**エラーにならずに壊れた値が入ります。**

`TCOV` / `RCOV` は「非蓄積系ソフト用」の補てん情報です。**過去を貯めるソフトには
不要です。** 蓄積せずに毎週のレースだけを扱うソフト向けに、関連マスタと過去走を
まとめて配るためのものです。

## セットアップで遡れる範囲

**「何年前まで取れるか」は仕様書に書いてあります。** JV-Data仕様書の
「データ種別一覧」シート、（３）セットアップデータの節です。

**レコードごとに違います。** レース詳細は1986年からありますが、3連単オッズは
2004年8月からしかありません。

| レコード | 内容 | 収録開始 |
| :--- | :--- | :--- |
| `RA` `SE` `HR` `H1` | レース詳細・馬毎・払戻・票数 | **1986年以降** |
| `UM` `BR` `BN` `RC` | 競走馬・生産者・馬主・レコードマスタ | 1986年以降 |
| `HN` `SK` | 繁殖馬・産駒マスタ | 1986年以降 |
| `O1` `O2` | オッズ（単複枠・馬連） | 1993年6月以降 |
| `HS` | 競走馬市場取引価格 | 1997年以降 |
| `O3` | オッズ（ワイド） | 1999年10月以降 |
| `YS` | 開催スケジュール | 2000年以降 |
| `HY` | 馬名の意味由来 | 2000年産駒以降 |
| `DM` | タイム型マイニング予想 | 2001年9月以降 |
| `O4` `O5` | オッズ（馬単・3連複） | 2002年6月以降 |
| `HC` | 坂路調教 | 2003年以降 |
| `H6` `O6` | 票数・オッズ（3連単） | 2004年8月以降 |
| `CK` | 出走別着度数 | 2004年以降 |
| `TM` | 対戦型マイニング予想 | 2010年4月以降 |
| `WF` | 重勝式（WIN5） | 2011年4月以降 |
| `JG` | 競走馬除外情報 | 2011年6月以降 |
| `WC` | ウッドチップ調教 | 2021年7月27日以降 |
| `KS` `CH` `BT` `CS` | 騎手・調教師・系統・コース情報 | 全件 |

**`TOKU`（`TK` 特別登録馬）は例外です。** セットアップ（option=3・4）で取れるのは
今週・来週分のみです。過去分は開始時刻を指定した通常データ（option=1）で取得します。
これは [JV-Linkインターフェース仕様書 4.9.0.1 p.21 注1](https://jra-van.jp/dlb/sdv/sdk/JV-Link4901.pdf#page=21)
の指定です。ただし、ハンデ発表後の通常データの提供期間は1年間です
（[JV-Data仕様書「データ提供タイミング･提供単位」](https://jra-van.jp/dlb/sdv/sdk/JV-Data4901.pdf#page=54)）。
2026年9月時点で2023年まで遡って取得することはできず、保存済みのデータがなければ
レース情報などと同じ期間には揃いません。

> [!WARNING]
> **古い年を指定しても、全部の表が揃うわけではありません**
>
> たとえば `--years 30`（1996年から）を指定しても、3連複オッズは2002年6月以降、
> 3連単は2004年8月以降のぶんしか入りません。**「取得できた年数」と
> 「分析に使える年数」は別物です。**
>
> 馬券の期待値を扱うなら、実質の下限は**3連単・3連複を使うかどうかで決まります。**

## option とデータ種別の組み合わせ

**組み合わせが不正だと `JVOpen` は `-116` を返します。** 仕様書の一覧はこうです。

| option | 指定できるデータ種別ID |
| :--- | :--- |
| 1（通常データ） | TOKU RACE DIFF BLOD SNAP SLOP WOOD YSCH HOSE HOYU COMM MING **DIFN BLDN SNPN HOSN** |
| 2（今週データ） | TOKU RACE TCOV RCOV SNAP TCVN RCVN SNPN |
| 3・4（セットアップ） | TOKU RACE DIFF BLOD SNAP SLOP WOOD YSCH HOSE HOYU COMM MING **DIFN BLDN SNPN HOSN** |

**補てん情報（`TCOV` `RCOV` `TCVN` `RCVN`）は option=2 でしか取れません。**
セットアップでも通常データでも指定できません。

## 速報系 — キーを指定して取る

`JVRTOpen(種別, キー)` で取ります。**期間では指定できません。**

| ID | 名称 | 取得の単位 | 含まれるレコード | 提供期間 |
| :--- | :--- | :--- | :--- | :--- |
| `0B12` | 速報レース情報（成績確定後） | 開催日 or レース | RA SE HR | 1週間 |
| `0B15` | 速報レース情報（出走馬名表〜） | 開催日 or レース | RA SE HR | 1週間 |
| `0B30` | 速報オッズ（全賭式） | **レース毎** | O1 O2 O3 O4 O5 O6 | 1週間 |
| `0B31`〜`0B36` | 速報オッズ（賭式別） | **レース毎** | O1 〜 O6 | 1週間 |
| `0B20` | 速報票数（全賭式） | レース毎 | H1 H6 | 1週間 |
| `0B11` | 速報馬体重 | 開催日 or レース | WH | 1週間 |
| `0B14` | 速報開催情報（一括） | 開催日 | WE AV JC TC CC | 1週間 |
| `0B16` | 速報開催情報（指定） | 変更情報単位 | WE AV JC TC CC | 1週間 |
| `0B13` | 速報タイム型マイニング予想 | 開催日 or レース | DM | 1週間 |
| `0B17` | 速報対戦型マイニング予想 | 開催日 or レース | TM | 1週間 |
| `0B41` | **時系列オッズ（単複枠）** | レース毎 | O1 | **1年間** |
| `0B42` | **時系列オッズ（馬連）** | レース毎 | O2 | **1年間** |
| `0B51` | 速報重勝式（WIN5） | 重勝式開催毎 | WF | 1週間 |

キーの形は、取得の単位で決まります。

| 単位 | キーの形 | 例 |
| :--- | :--- | :--- |
| 開催日 | `YYYYMMDD` | `20260906` |
| レース | `YYYYMMDDJJKKHHRR` | `2026090506040109` |

`JJ`=競馬場コード、`KK`=開催回、`HH`=開催日目、`RR`=レース番号です。

> [!WARNING]
> **オッズは開催日単位で取れません**
>
> `0B30`〜`0B36` と `0B41`/`0B42` は**レース毎**です。1日ぶん集めるには、
> レース数だけ `JVRTOpen` を呼ぶことになります。仕様上、まとめて取る方法は
> ありません。

### 開催日の速報をまとめて取る — `jvstore realtime`

発走前に要る速報を、開催日を1つ指定して一度に取ります（画面なら「速報の取得」）。
種別ごと・レースごとに `jvstore rt` を打つ代わりです。

```powershell
uv run jvstore realtime --date 2026-09-20
```

開催日単位の `0B15`・`0B14`・`0B11`・`0B13`・`0B17` を先に取り、そのあと `0B31`（単勝・複勝・枠連）を
その日の中央のレースの数だけ呼びます。レースの一覧は、先に取った `0B15` の `ra` から拾います。
まだ発表されていない種別（前日の馬体重など）は「該当データなし」で、失敗にはなりません。
段取りは `src/jvstore/realtime.py` にあります。

### 時系列オッズは過去1年ぶん取れます

**速報系で唯一、提供期間が1年ある種別です。** 過去のレースについても、
レースキーを指定すれば発走までの5分刻みの断面が取れます。

| 何が取れるか | 種別ID | レコード |
| :--- | :--- | :--- |
| 単勝・複勝・枠連 | `0B41` | O1 |
| 馬連 | `0B42` | O2 |

**ワイド・馬単・3連複・3連単の時系列オッズは存在しません。** 発走前の値が
必要なら、単勝オッズから合成するか、当日に自分で取って貯めるしかありません。

## 速報系でしか取れないもの

次の6レコードは蓄積系のどの種別にも含まれません。**1週間で消えます。**

| レコード | 内容 | 種別ID |
| :--- | :--- | :--- |
| `WH` | 馬体重 | `0B11` |
| `WE` | 天候馬場状態 | `0B14` / `0B16` |
| `AV` | 出走取消・競走除外 | 〃 |
| `JC` | 騎手変更 | 〃 |
| `TC` | 発走時刻変更 | 〃 |
| `CC` | コース変更 | 〃 |

> [!NOTE]
> **速報開催情報は取り消されることがあります**
>
> 仕様書に明記されています。騎手変更が発表されたあとに取り消されると、
> 速報開催情報から該当データが**削除されます**。
>
> そのため速報開催情報は、**取得するたびに前回ぶんを破棄し、
> その時点で含まれている情報だけを使う**必要があります。差分として
> 貯め込む使い方はできません。

## 本ツールが使う12種別

`jvstore sync` は次の12種別を回します。**この組み合わせで蓄積系の32表を
取得対象にします。** 各表の収録開始・提供期間は異なり、`TOKU` の過去分は
`fetch --dataspec TOKU --option 1` に開始時刻を指定して別途取得する必要があります。

```
RACE  DIFN  BLDN  SNPN  MING  SLOP
WOOD  YSCH  HOSN  HOYU  COMM  TOKU
```

補てん情報（`TCOV` `RCOV`）は、過去を貯める用途には要らないので外しています。
旧種別（`DIFF` `BLOD` `SNAP` `HOSE`）は上記のとおり使いません。
