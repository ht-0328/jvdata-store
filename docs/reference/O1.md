## キー

この組み合わせで1件が決まります（仕様書の「キー」列）。

1. 開催年
2. 開催月日
3. 競馬場コード
4. 開催回[第N回]
5. 開催日目[N日目]
6. レース番号

## 繰返しブロック

本ツールでは、繰返しブロックは**子テーブルに分けます**（横に並べると列数が扱えなくなるため）。

| ブロック | 繰返し | 1回分のバイト数 | 子テーブル名 |
| :--- | ---: | ---: | :--- |
| 単勝オッズ | 28 | 0 | `o1__単勝オッズ` |
| 複勝オッズ | 28 | 0 | `o1__複勝オッズ` |
| 枠連オッズ | 36 | 0 | `o1__枠連オッズ` |
