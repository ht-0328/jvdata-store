# WH — 馬体重

| | |
| :--- | :--- |
| レコード種別ID | `WH` |
| 表番号 | 101 |

| 項目数 | 12 |
| 区分 | 速報系のみ |
| DuckDB のテーブル名 | `wh` |

## キー

この組み合わせで1件が決まります（仕様書の「キー」列）。

1. 開催年
2. 開催月日
3. 競馬場コード
4. 開催回[第N回]
5. 開催日目[N日目]
6. レース番号

## 繰返しブロック

本ツールでは、繰返しブロックは**子テーブルに分けます**（横に並べると列数が扱えなくなるため）。

| ブロック | 繰返し | 1回分のバイト数 | 子テーブル名 |
| :--- | ---: | ---: | :--- |
| 馬体重情報 | 18 | 2 | `wh__馬体重情報` |
