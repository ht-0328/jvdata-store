## キー

この組み合わせで1件が決まります（仕様書の「キー」列）。

1. 開催年
2. 開催月日
3. 競馬場コード
4. 開催回[第N回]
5. 開催日目[N日目]
6. レース番号

## 全項目

「位置」は1始まりのバイト位置です。繰返しブロックの中の項目は、ブロック先頭からの相対位置を `(+n)` で示します（0始まり）。
