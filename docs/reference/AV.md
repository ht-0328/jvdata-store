# AV — 出走取消・競走除外

| | |
| :--- | :--- |
| レコード種別ID | `AV` |
| 表番号 | 103 |
| レコード長 | 78 バイト |
| 項目数 | 14 |
| 区分 | 速報系のみ |
| DuckDB のテーブル名 | `av` |

## キー

この組み合わせで1件が決まります（仕様書の「キー」列）。

1. 開催年
2. 開催月日
3. 競馬場コード
4. 開催回[第N回]
5. 開催日目[N日目]
6. レース番号
7. 馬番

## 全項目

「位置」は1始まりのバイト位置です。繰返しブロックの中の項目は、ブロック先頭からの相対位置を `(+n)` で示します（0始まり）。
