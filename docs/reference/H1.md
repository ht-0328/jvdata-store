## キー

この組み合わせで1件が決まります（仕様書の「キー」列）。

1. 開催年
2. 開催月日
3. 競馬場コード
4. 開催回[第N回]
5. 開催日目[N日目]
6. レース番号

## 繰返しブロック

本ツールでは、繰返しブロックは**子テーブルに分けます**（横に並べると列数が扱えなくなるため）。

| ブロック | 繰返し | 1回分のバイト数 | 子テーブル名 |
| :--- | ---: | ---: | :--- |
| 単勝票数 | 28 | 0 | `h1__単勝票数` |
| 複勝票数 | 28 | 0 | `h1__複勝票数` |
| 枠連票数 | 36 | 0 | `h1__枠連票数` |

## 連番になる項目

内訳を持たない繰返し項目は、子テーブルにはせず**連番付きの列**に展開します。
`本賞金` が7回繰返しなら `本賞金_1` 〜 `本賞金_7` になります。

| 項目 | 繰返し | 展開後の列名 |
| :--- | ---: | :--- |
| 返還馬番情報(馬番01～28) | 28 | `返還馬番情報(馬番01～28)_01` 〜 `返還馬番情報(馬番01～28)_28` |
| 返還枠番情報(枠番1～8) | 8 | `返還枠番情報(枠番1～8)_1` 〜 `返還枠番情報(枠番1～8)_8` |
| 返還同枠情報(枠番1～8) | 8 | `返還同枠情報(枠番1～8)_1` 〜 `返還同枠情報(枠番1～8)_8` |
